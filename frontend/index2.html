BAYESIAN PRIOR DEBIASING

Correcting Class Skewness

Reddit discourse is 72.8% Normal, while wearable data is 41.1% Mild. We cancel this training distortion through Bayesian Prior Division:

P_unbiased = P_raw / P_training_prior
ADAPTIVE ALPHA WEIGHTING

Dynamic Modality Arbitration

When linguistic input is rich (>80 chars), text weight scales to α = 0.50. In sparse input, the system gracefully relies on wearable physiological telemetry (α = 0.05).

P_fused = α · P_text + (1 - α) · P_wearable
